# События бота только через Webhook

---
status: accepted
---

MAX умеет отдавать апдейты двумя способами, но одновременно их включать нельзя. Берём **Webhook** (`POST /subscriptions` на `https://max-sport.sabirov.tech/webhook`) с первого дня, включая разработку. Long Polling (`GET /updates`) не используем.

## Considered Options

1. **Long Polling** — проще на ноутбуке без домена, но в доке MAX это не production: лимиты скорости и срока хранения событий. Для питча и живой Карточки чата канал должен совпадать с продом.
3. **Webhook сразу (выбрано)** — домен уже есть, HTTPS обязателен в любом случае для Mini App.

## Consequences

- Процесс должен отвечать `200` на webhook за 30 секунд; молчание 8 часов — MAX сам отписывается.
- Подписку регистрируем при старте. Секрет `X-Max-Bot-Api-Secret` обязателен.
- Локальная отладка — через тот же HTTPS-endpoint (туннель или сразу VPS), не через polling.
