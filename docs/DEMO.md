# Demo-path для питча (PRODUCT §6)

Прогонять перед защитой. Запас: screencast на телефоне.

## Подготовка

1. На VPS: `.env` с `MAX_BOT_TOKEN`, `WEBHOOK_SECRET`, `POSTGRES_PASSWORD`
2. Seed (после первого входа в Mini App): `npm run migrate -w @maxsport/api` (включает `003_pitch_seed.sql` если пользователь есть)
3. Заранее создать «горящее» Лобби: 1 свободный Слот «Связующий», старт через 2–3 часа

## Сценарий live

| Шаг | Действие | Ожидание |
| --- | --- | --- |
| 1 | Организатор: Create Lobby → волейбол, 12 слотов, 1 связующий | Лобби в ленте |
| 2 | «Поделиться в MAX» → карточка в групповой чат | Карточка с кнопками |
| 3 | Игрок: «Занять слот» в чате | `12/12`, карточка обновилась |
| 4 | T−30 / «Я на месте» | Ростер зеленеет |
| 5 | «Начинаем» → «Завершить» → Карма | Бейдж в паспорте |
